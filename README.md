Student Profile App

This project is a simple Student Profile App created using React Native, Expo and TypeScript.

The app allows users to enter their name and favourite subject. When the user presses the Show My Profile button, the app displays a personalised message.

Step 2 - Explain My Design

1. Which components did you use?

I used View, Text, Image, TextInput, Pressable, ScrollView and StyleSheet. I also used useState to store the information entered by the user.

2. Why did you choose those components?

I chose these components because they each have a different purpose. View helps organise the layout, Text displays information, Image displays the avatar, and TextInput allows users to enter their details. Pressable creates an interactive button, while StyleSheet controls the appearance of the app.

3. How did you organise the components?

I organised the components vertically, with the heading and profile image at the top, followed by a description, two text inputs and a button. I used spacing and a green colour scheme to make the interface look organised.

4. How does the user interact with your interface?

The user enters their name and favourite subject into the two text inputs. After pressing the Show My Profile button, the app displays a personalised message using the information entered.

5. What part of your interface are you least confident about?

I am least confident about positioning components correctly on different screen sizes. I still need more practice with flexbox, spacing and alignment.
